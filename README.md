# mywrapclaude

Dépôt de veille personnelle : fiches structurées produites à partir de sources
(vidéos YouTube, articles, docs…) sur l'IA, les outils agentiques et leurs
usages en conseil / formation.

## Arborescence

```
.
├── README.md              # ce fichier
└── veille/
    ├── README.md          # index des fiches + format
    ├── _template.md       # gabarit pour une nouvelle fiche
    └── <fiches>.md        # une fiche = une source traitée
```

## Ajouter une fiche

1. Copier `veille/_template.md` vers `veille/<sujet-court>.md`.
2. Remplir les sections.
3. Ajouter une ligne dans le tableau de `veille/README.md`.
